14. Color Sensor ​

14.1 Introduction ​

Built around a high-sensitivity optical sensing chip, the color sensor evaluates light intensity across distinct wavelengths to identify complex target colors. It converts red, green, blue, and infrared light into clean digital signals. Thanks to its wide dynamic range, the sensor delivers reliable color readings in both dim corners and brightly lit rooms.

14.2 Technical Specifications ​

ParameterDescription
Operating voltage5 V
Color detectionDetects RGB colors and infrared light intensity
Detection distance15 ± 2 mm

14.3 Hands-On Project ​

14.3.1 Project Introduction ​

This project programs the color sensor to identify red, green, and blue targets. Detecting a target color prompts the buzzer to play a distinct musical note. When no matching color is found, the buzzer turns off, providing immediate audio feedback based on optical recognition.

14.3.2 Hardware Wiring ​

  • Connect the color sensor to port A of the controller using a 4-pin module cable.

NOTE

This sensor supports connection to any port among A, B, C, or D on the controller. Ensure that the port selected in the program matches the physical wiring.

14.3.3 Adding Extensions ​

  • Select Color recognition sensor under the Input Module category.

14.3.4 Complete Program and Analysis ​

  1. On start-up, set the color sensor to port A.

  2. In the main loop, continuously detect colors and trigger buzzer tones:

    • Red detected: Play note C8 for half a beat in the background.

    • Green detected: Play note C5 for half a beat in the background.

    • Blue detected: Play note C2 for half a beat in the background.

    • Otherwise: Turn off the buzzer, then repeat the loop.

NOTE

The source files are available for download under Program Files/ 14 Color Sensor.sb3.

14.3.5 Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

14.3.6 Program Outcome ​

Once the program upload is complete, bring different colored blocks close to the color sensor. When red is detected, the buzzer plays note C8. When green is detected, the buzzer plays note C5. When blue is detected, the buzzer plays note C2. Moving the colored block away silences the buzzer immediately.
