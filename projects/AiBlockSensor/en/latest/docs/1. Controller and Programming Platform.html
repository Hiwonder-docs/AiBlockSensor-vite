1. Controller and Programming Platform ​

1.1 AiBlock Controller ​

1.1.1 Introduction ​

Powered by the ESP32 chip, the AiBlock controller supports graphical block programming and Python coding. The controller features a durable PC plastic housing and incorporates onboard PWM servo ports, motor ports, programmable buttons, and a buzzer. It provides multiple sensor ports for extensive expansion capability. The standardized 4-pin keyed ports seamlessly accommodate AiBlock series sensors, ensuring convenient and reliable connections.

NOTE

The three port types cannot be mixed. Ports M1-M4 connect exclusively to long motors. Ports A-D connect to various sensors. Ports S1-S4 connect to block servos and standard block motors. Incorrect connections may damage the controller and accessories.

1.1.4 Powering On and Charging Instructions ​

(1) Powering On ​

Turn on the power switch as shown in the diagram. The power indicator LED on the controller lights up, confirming a successful startup.

(2) Charging Instructions ​

  1. Set the power switch of the controller to OFF. Connect one end of the Type-C cable to the charging port of the controller, and connect the other end to the charger.
  1. During charging, the indicator LEDs on the controller display the current charging status. All 4 white LEDs light up once charging is complete. Disconnect the power cable promptly after charging to prevent overcharging.

NOTE

The power switch must be turned off during charging. Otherwise, the battery may fail to charge fully. Disconnect the charger and power source promptly after charging is complete to avoid battery damage caused by overcharging.

1.2 WonderLab Programming Platform ​

1.2.1 Introduction ​

WonderLab is a dedicated Scratch programming platform designed for Hiwonder products. The software supports automatic conversion between graphical code blocks and Python code. Programs are constructed simply by dragging and dropping code blocks, providing an intuitive environment for introductory programming.

1.2.2 System Requirements ​

Windows 7 or Windows 10 operating system, serial port driver.

1.2.3 Installation Steps ​

  1. Click the link below to download the installation package:

WonderLab Programming Platform Download for Windows

  1. Open the WonderLab.exe installation file.
  1. Select the preferred language, then click OK.
  1. Select the destination installation directory, then click Next.
  1. Click Next.
  1. Click Install.
  1. Once installation is complete, click Finish. The software launches automatically.

1.2.5 Hands-On Project ​

(1) Project Introduction ​

This project uses the onboard buzzer and programmable buttons on the controller to loop the C2 tone. Short-pressing the left or right button adjusts the buzzer volume. The lesson introduces loop blocks, button event triggers, and buzzer volume control, building familiarity with concurrent multi-event handling.

(2) Creating a New Project ​

Open the software, then click the file icon in the upper-left corner. Click ① to create a new project, and modify the project name at ②.

(3) Adding Extensions ​

  1. Click the Extensions button in the lower-left corner.
  1. Select AI Blocks Board under the Controller category.
  1. Once added, the loaded extension package appears on the WonderLab interface.

(4) Writing the Program ​

Drag the corresponding blocks from the blocks palette to the script canvas to assemble the program. Once created, the converted Python code appears in the code display panel on the right.

NOTE

The source files are available for download under Program Files / 01 Buzzer.sb3.

(5) Program Upload ​

  1. Connect one end of the data cable to the Type-C port located next to the power switch on the controller.
  1. Connect the other end of the data cable to a computer USB port.
  1. Click Connect device, then select the corresponding serial port.

NOTE

Port numbers vary across computers. The example in this section uses COM17. Avoid selecting COM1, which is typically reserved for system communications. When multiple COM ports are listed, right-click "This PC", select "Properties", open "Device Manager", and locate the port marked with "CH340". If no port ending with CH340 appears, the driver may be missing. Refer to 1.2.6 Installing Driver for driver installation instructions.

  1. Click the upload button in the upper-right corner to upload the program to the controller.

(6) Program Outcome ​

Once the program upload is complete and the controller powers on, the buzzer repeatedly plays tone C2 at 1-second intervals. Short-pressing the left button sets the buzzer volume to 100, the maximum level, for 2 s. Short-pressing the right button sets the volume to 50, a moderate level, for 2 s. The tone loop continues uninterrupted, allowing volume adjustments at any time via the buttons.

1.2.6 Installing Driver ​

  1. Open the programming software, navigate to Help, and click Install driver.
  1. In the pop-up window, click UNINSTALL. Once the uninstallation finishes, click INSTALL to install the new driver. Wait until the installation success prompt appears.
