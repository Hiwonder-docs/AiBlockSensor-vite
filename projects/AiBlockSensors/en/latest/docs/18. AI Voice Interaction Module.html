18. AI Voice Interaction Module ​

18.1 Introduction ​

This section introduces the AI voice interaction module, which provides speech recognition and voice broadcasting powered by the CI1302 neural processor. The module incorporates offline neural network acceleration and dedicated audio signal processing hardware, extracting spoken commands accurately through deep noise reduction. It activates via a designated wake-up word, entering an active listening state for subsequent voice recognition.

Featuring straightforward operation and reliable speech recognition, this module serves diverse applications, including smart home prototypes, conversational bots, educational robots, and vehicle dispatch terminals.

18.4 Voice Interaction Testing ​

  1. Connect the Type-C port on top of the AI voice interaction module to a computer port or phone charger using a USB cable for power supply.
  1. Taking the command word Go straight as an example for speech testing, first state the wake-up word Hello Hiwonder to activate the module. When the module replies with I'm here, it indicates readiness for voice recognition.
  1. Next, speak the command word Go straight to the module to trigger the corresponding voice response.
  1. Speaking any of the following command words also prompts WonderEcho to broadcast the corresponding response phrase.

18.5 Hands-On Project ​

18.5.1 Project Introduction ​

This project programs the AI voice interaction module to poll and process spoken commands continuously in a loop. When the module detects specific voice commands, the controller prints corresponding feedback messages to the serial monitor. Working through this project covers module port initialization, voice result polling, and multi-branch conditional logic.

18.5.2 Hardware Wiring ​

  • Connect the AI voice interaction module to port A of the controller using a 4-pin module cable.

NOTE

This module supports connection to any port among A, B, C, or D on the controller. Ensure that the port selected in the program matches the physical wiring.

18.5.3 Adding Extensions ​

  • Select WonderEcho speech module under the Input Module category.

18.5.4 Complete Program and Analysis ​

  1. Upon power-on, initialize the hardware port of the AI voice interaction module to port A.

  2. In the main program, continuously refresh and read recognition results from the AI voice interaction module inside a loop:

    • Update and retrieve speech recognition results.

    • When the command go straight is recognized, print Go forward! to the serial monitor.

    • When the command go backward is recognized, print Go back! to the serial monitor, then continuously repeat the voice command detection loop.

NOTE

The source files are available for download under Program Files/ 21 AI Voice Module.sb3.

18.5.5 Program Upload ​

  • Click Connect device, select the serial port, then click the upload button. Wait for the upload success notification to complete the program transfer.

18.5.6 Program Outcome ​

After uploading the program, the module powers on and completes initialization. Once awakened with Hello Hiwonder, speaking go straight prompts the serial monitor to print Go forward!. Speaking go backward prints Go back!. The system continuously listens for incoming voice commands.

18.6 Firmware Flashing ​

NOTE

The module comes pre-flashed with factory firmware, so reflashing is not required under normal circumstances. This section is intended only for firmware updates or recovery when firmware corruption occurs.

  1. Connect the Type-C port on top of the AI voice interaction module to a computer using a USB cable.
  1. Open the PACK_UPDATE_TOOL file located inside the Appendix File\02 AI Voice Module Files\Flashing-tool folder.
  1. Select the CI1302 chip, then click Update.
  1. Click Select firmware to choose the bin firmware file to flash: navigate to the WonderEcho Flash‑firmware 20260901.bin file inside the Appendix File\02 AI Voice Module Files\02 Flashing Firmware folder.
  1. Locate the corresponding serial port and click to select it.
  1. Press the RST button on the voice interaction module to enter flashing mode, then wait for the flashing process to complete successfully.
